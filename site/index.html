CAP 04StandardScaler

Padroni­zação

μ = 0σ = 1

Altura vai de 155 a 205 cm, finalização de 0 a 100, reputação de 1 a 5. Sem padronizar, o PCA confunde "escala grande" com "informação". Cada coluna perde a média e é dividida pelo desvio-padrão do treino.

① ENTRA

a tabela de treino, com cada coluna na sua unidade: cm, kg, nota de 0 a 100, estrelas de 1 a 5.

② NA TELA

a distribuição de três atributos. Ao padronizar, as três ficam centradas no 0 e com a mesma largura.

③ SAI

Z: a mesma tabela medida em “desvios da média”. 0 é um jogador médio; +2 é muito acima da média.

Z-SCORE
zij = xij − μjσj
xij
valor do jogador i no atributo j
μj
média do atributo no treino
σj
desvio-padrão do atributo no treino
CAP 0537 × 37 = 1.369 pares

Correla­ção

—pares com |r| ≥ 0,8

Muitas colunas contam a mesma história: quem dribla bem também controla bem a bola, e todo goleiro é bom em todos os atributos de goleiro. É essa redundância que o PCA vai comprimir.

① ENTRA

Z, a tabela padronizada do treino (13.610 × 37).

② NA TELA

cada quadradinho é um par de atributos. Laranja: sobem juntos. Azul: um sobe e o outro desce. Escuro: sem relação.

③ SAI

C, uma matriz 37 × 37 que resume como cada par de atributos anda junto. É dela que saem os componentes.

MATRIZ DE COVARIÂNCIA
C = 1n − 1 Z⊤Z

com Z padronizado, C é a matriz de correlação: Cjk = r(atributo j, atributo k)

    que mais varia

    C v = λ vautovetores

    Com só dois atributos, finalização e desarme, dá para ver o que o PCA faz: girar uma reta até a sombra dos jogadores sobre ela ficar o mais espalhada possível. Arraste na tela para girar a reta. Com 37 atributos a busca é a mesma, em 37 dimensões.

    ① ENTRA

    a matriz C. Aqui, só 2 dos 37 atributos para caber numa tela plana.

    ② NA TELA

    cada ponto é um jogador do treino; a reta é uma direção candidata e os traços ligam cada jogador à sua sombra na reta. A curva mostra o espalhamento das sombras em cada ângulo.

    ③ SAI

    W: as 2 melhores direções (PC1 e PC2), cada uma com 37 pesos, um para cada atributo.

    PROBLEMA
    w1 = arg max‖w‖ = 1 Var(Z w) = w⊤C w
    ⇒ C w1 = λ1 w1

    o PC1 é o autovetor de C com o maior autovalor; o PC2 é o próximo, perpendicular ao primeiro.

      !Limitações

      • Atributos de videogame. Notas da EA Sports para a temporada 2018/19, não medições reais.
      • Rótulo simplificado. 27 posições viram 4 grupos; boa parte dos "erros" está nas fronteiras que nós definimos.
      • PCA é linear. Relações não lineares escapam, e cada eixo mistura todos os atributos.
      • Não use para avaliar, contratar ou escalar jogadores reais.
